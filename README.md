\# 🌤 Telegram Weather Bot



Telegram-бот для получения подробного прогноза погоды по названию города.



\## 📌 О проекте



Бот позволяет пользователю указать город и получить актуальный прогноз погоды.



Прогноз содержит:



\- 🌡 температуру;

\- 🌡 ощущаемую температуру;

\- ☁️ описание погодных условий;

\- 💨 скорость ветра;

\- 💨 порывы ветра;

\- 💧 влажность;

\- 🌧 вероятность осадков;

\- 🌅 время восхода солнца;

\- 🌇 время заката;

\- 📅 прогноз на 7 дней.



Прогноз на текущий день разделён на четыре периода:



\- 🌙 Ночь

\- 🌅 Утро

\- ☀️ День

\- 🌆 Вечер



\## 🛠 Используемые технологии



\- \*\*Python 3\*\*

\- \*\*python-telegram-bot\*\* — работа с Telegram Bot API

\- \*\*Open-Meteo\*\* — получение данных о погоде

\- \*\*httpx\*\* — HTTP-запросы

\- \*\*python-dotenv\*\* — работа с переменными окружения
